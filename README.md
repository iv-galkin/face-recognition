# Пайплайн задачи распознавания лиц (Face Recognition)

---

## Цель исследования
Познакомиться с задачей распознавания лиц, функцией потерь ArcFace, метрикой Identification Rate, построить свой пайплайн для решения этой задачи. Добиться правильности (accuracy) классификации лиц > 70%. Выяснить, использование какой из функций потерь (ArcFace loss или Cross Entropy loss) даёт лучшее качество по метрике Identification Rate. 

---

## Постановка задачи
Допустим, некоторая компания хочет разработать систему распознавания лиц, чтобы применять ее в своем офисе. Например, чтобы сотрудники могли сканировать лицо вместо прикладывания id-карточек к турникетам при входе. Или для обеспечения безопасности в офисе. 

Таким образом, нужна система, которая может принимать на вход фото, полученное с камер наблюдения, и идентифицировать на фото сотрудника. Такая система должна уметь работать в случаях, когда лица людей запечатлены крупным или мелким планом, когда они чуть повернуты или наклонены, и когда на одном кадре с камеры находятся несколько лиц.

Написанный пайплайн может использоваться, например, для решения описанной задачи, а также для ряда других задач, где необходимо распознавать лица. 

---

## Проблема, которую решает проект
Система распознавания лиц может заменить традиционные методы контроля доступа (например, ID-карты), повысить уровень безопасности в офисах и обеспечить автоматизированный анализ видеопотоков с камер наблюдения.

## Основные итоги
- Проведено сравнение ResNet50, ResNet34 и ResNet18 в задаче классификации лиц, оптимальную скорость обучения и сходимость функции потерь на нашем датасете показала ResNet34;
- Реализована функция потерь ArcFaceLoss;
- Реализована метрика Identification Rate для задачи распознавания;
- Обучена модель ResNet34 c функцией потерь ArcFace, качество классификации на тесте 76.7%;
- Обучена модель Resnet34 c функцией потерь Cross Entropy, качество классификации на тесте 72%;
- Создан датасет на основе LFW, на котором обучена собственная модель поиска ключевых точек;
- Построен пайплайн для распознавания лиц, включая детекцию, выравнивание и классификацию;
- По метрике Identification Rate модель, обученная на CE Loss, лучше себя показывает в задаче распознавания.
